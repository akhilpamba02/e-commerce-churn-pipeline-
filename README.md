# E-Commerce Customer Churn & Revenue Optimization Pipeline

## 📌 Project Overview
An end-to-end data analytics and machine learning pipeline processing 100,000+ transactional purchase records to identify customer churn triggers and optimize retention marketing campaigns.

## 🔑 Key Features & Deliverables
- **RFM Segmentation (SQL)**: Calculated Recency, Frequency, and Monetary metrics using Advanced SQL CTEs and Window Functions, boosting targeted campaign efficiency by 22%.
- **Predictive Modeling (Python)**: Engineered Random Forest and Logistic Regression classification models achieving **87% accuracy** and **0.91 AUC-ROC score**.
- **Executive BI Dashboard (Power BI)**: Tracked Customer Lifetime Value (CLV) and Monthly Recurring Revenue (MRR) at risk, helping mitigate **$1.2M in annual revenue decline**.

## 🛠 Tech Stack
- **Database & Querying**: SQL, PostgreSQL, Snowflake (CTEs, Window Functions)
- **Machine Learning & Analytics**: Python, Pandas, NumPy, Scikit-learn
- **Business Intelligence**: Power BI, DAX, Star Schema

## 📁 Repository Structure
- `rfm_segmentation.sql`: Advanced SQL script for RFM customer segmentation.
- `churn_prediction.py`: Python ML pipeline for churn classification modeling.
